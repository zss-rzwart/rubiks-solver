# rubiks-solver

An Angular website that teaches how to solve the 3x3 and 2x2 Rubik's Cube.
Recurring sub-algorithms (e.g. the 4-move "Sexy Move" `R U R' U'`) are automatically
detected, named and colour-coded wherever they appear (see `src/app/notation/algorithm.ts`).

## Plan
1. **Notation + colour-coded sub-algorithms** (done)
2. **Beginner solves** for 3x3 and 2x2 (done, text + algorithms)
3. Intermediate (F2L, 2-look OLL/PLL) – placeholder page
4. Advanced (full OLL/PLL) – placeholder page
5. Later: cube diagrams / 3D visualisation, more named sub-algorithms

## Commands
`npm start` (dev server), `npm run build`, `npm test`
